### Pipeline
Below is the series of steps needed to prepare your own repeat library for curation. <b><ins>Within each README.md file</b></ins> is a script and description of the commands. For this workshop, the fire ant is used as an example. 
1. [De novo repeat discovery](RepeatModeler2.md) (RepeatModeler)
2. [Collect more copies](RepeatMasker.md) (RepeatMasker)
3. [Generate seed alignments](generateSeedAlignments.md) 
4. [Extending seed alignments](extendSeedAlignments.md)
5. [Get fasta consensus and elements](generateConsensusAndElements.md)
6. [Run ```alignAndCallConsensus.pl``` for each model](alignAndCallConsensus.md)
